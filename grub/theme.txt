#   - menu items deep purple #3F2470 (matches the desktop titlebar). The

#   - item_spacing 0 so rows are adjacent (uniform, and the snapshot columns --
#     box-drawing │ -- form a CONTIGUOUS vertical rule).
#   - fonts are 24px, sized for the panel's native-res boot. Percent geometry is
#     resolution-independent; the loader picks up every .pf2 in this dir.
